# AURA PowerDesk UK - Frontend

This is the React 19 + Vite frontend for **AURA PowerDesk UK**, a specialized day-ahead wholesale electricity procurement and renewable generation forecast analytics platform for UK energy utilities based on Elexon BMRS data.

For comprehensive documentation, client pitch, technical architecture review, and setup guide, please refer to the [Root README](../README.md).

## Local Development

```bash
# Install dependencies
npm install

# Start Vite dev server (with API proxy to http://127.0.0.1:8000)
npm run dev

# Build production bundle
npm run build
```
